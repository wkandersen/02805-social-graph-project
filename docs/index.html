05

Method & receipts

What exactly did we measure?

01

Representation

A node is a Marvel superhero Wikipedia article. A directed, unweighted edge A → B exists when A’s running article text links to B. Redirects are resolved; navbox links are excluded.

02

Construction

We added all 303 roster entries before the 1,784 edges, retaining 17 isolates. For components and density we collapsed reciprocal arrows into 1,434 undirected pairs.

03

Sanity checks

The script asserts n = 303, directed m = 1,784, undirected m = 1,434, and 17 isolates against the course data page before generating this site.

04

Human check — do this together

Open Spider-Man’s row in the edge list and count a small sample of incoming links by hand. Record who checked it and whether the count agreed before sharing the site.
