Method & receipts

What did we keep?

01

Representation

A node is a superhero article. An undirected, unweighted edge exists when either article links to the other. We analyse the 277-node giant component.

02

Models

ER matches n and m. WS uses mean degree 10 and rewiring q = 0.2. BA adds five links per arriving node. Seeds are fixed for reproducibility.

03

Null model

Each sample performs three edge swaps per edge after burn-in. All node degrees are asserted unchanged. The p-value uses (extreme + 1)/(samples + 1).

04

Human check
