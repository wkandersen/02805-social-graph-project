How this site works

01

One folder per week

Every week lives at its own permanent URL under /weekN/ with its own page, styles, and generated data. Nothing gets overwritten when the next week ships.

02

Data is generated, not hand-edited

Each week has a script at the repository root — analyse_week1.py, analyse_week2.py — that reads the frozen snapshot in data/ and writes the JSON its page consumes.

03

Numbers are asserted

The scripts assert n = 303, directed m = 1,784, undirected m = 1,434, and 17 isolates before writing anything, so a broken snapshot fails loudly instead of quietly.

04

Run it yourself

uv run analyse_week2.py regenerates the data, and serving the docs/ folder over HTTP reproduces this site exactly as published.
