04 · Shuffle rig

degree-preserving edge swaps

An Erdős–Rényi baseline deletes Marvel's hubs, so it cannot tell us whether hubs cause the triangles. Edge swaps keep every character's degree exactly and destroy only who is connected to whom — the baseline that asks the right question.

What surprised us

Hubs explain only half the clustering gap. Marvel falls from C = — to — once degrees are held fixed and everything else is scrambled — yet the survivor is still —σ beyond chance. Swap in a plain random graph and you would have credited the whole surplus to the hubs.

06 · Spec sheet

method & receipts
Representation
A node is a Marvel superhero Wikipedia article. An undirected, unweighted edge exists when either article links to the other. All measurements run on the 277-node giant component.
Models
Erdős–Rényi matches n and m. Watts–Strogatz uses degree 10 with rewiring q = 0.2. Barabási–Albert attaches 5 links per arriving node. One fixed seed per model, so every number on this page is one reproducible draw rather than an average.
Null model
120 samples, each applying three double-edge swaps per edge. The degree sequence is asserted unchanged. The p-value is (extreme + 1)/(samples + 1), so 120 shuffles can never report zero.
Human check
Not done by the machine: pull one shuffled snapshot, confirm by hand that Spider-Man still has 106 neighbours while the names in that list have changed. Record who checked before publishing.
Reproduce
